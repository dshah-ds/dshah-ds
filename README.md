## How I work

I spent years keeping a bank's systems reliable. Now I bring that discipline to data:

- **I validate before I trust a number.** My first Chicago crime model scored 99.8%. It was data leakage. I removed the leaking feature, rebuilt the pipeline and published the honest 77.4%.
- **I document so the next person can pick it up.** Every repo here has a README that explains the *why*, not just the *what*.
- **I ship end to end.** I host my own sites on Azure Static Web Apps with GitHub Actions CI/CD, and I use GenAI (Claude, ChatGPT, Emergent, Higgsfield) as a daily engineering partner.
